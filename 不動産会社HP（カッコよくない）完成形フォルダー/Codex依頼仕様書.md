## 1. プロジェクト概要

### 1.1 サイトの目的
1. 売却を検討するオーナー・法人・地主からの **売却相談**を獲得する（主目的）。
2. 投資家からの **購入相談**および **未公開物件メール会員登録**を獲得する（副目的）。
3. 注文住宅検討者からの **住宅会社紹介サービス相談**を獲得する（副目的）。

### 1.2 メインターゲット
- **売却側**: 築古一棟アパート・収益不動産を所有する個人オーナー、法人、地主。
- **購入側**: 個人投資家から法人まで幅広く（中上級者を想定）。
- **注文住宅側**: マイホーム建築を検討中で、ハウスメーカー選びに迷っている家族層。

### 1.3 事業内容（2 本柱）
| 事業 | 概要 | サイト上の比重 |
|---|---|---|
| ① 不動産売買仲介事業 | 築古一棟アパート・収益不動産が中心。土地・築浅・戸建も依頼ベースで対応。価格帯は絞らない。 | **メイン** |
| ② 注文住宅検討者向け 住宅会社紹介事業 | ヒアリングのうえ、提携 10 社から検討者に合うハウスメーカーを中立な立場で紹介。利用料無料。 | **サブ（事業内容ページ下部にコンパクト）** |

### 1.4 メッセージ・トーン
- 「**少しわかりやすく、でも本格的**」。中上級者の投資家にも刺さりつつ、個人オーナーも置いてけぼりにしない。
- 強み 3 軸: **① 築古一棟への専門特化 / ② 全国の買主ネットワーク / ③ 誠実な情報開示・課題も隠さない姿勢**。

## 2. 技術仕様

### 2.1 技術スタック
- **HTML5 / CSS3 / Vanilla JavaScript** のみ。ビルドツール・フレームワークは使わない。
- 外部 CDN は Google Fonts と Google Maps Embed のみに限定。
- フォーム送信は **Netlify Forms** を利用（後述）。
- **ヘッダー・フッターは各 HTML に同一のマークアップをコピペして埋め込む**（fetch・テンプレートエンジン不使用）。

- Chrome / Safari / Edge / Firefox 最新版および iOS Safari / Android Chrome。
- IE は非対応。
- ブレークポイント:
  - モバイル: `~ 767px`
  - タブレット: `768px ~ 1024px`
  - デスクトップ: `1025px ~`
- 最大コンテンツ幅: `1200px`。

### 2.4 Netlify 設定（`netlify.toml`）
```toml
[build]
  publish = "."

[[headers]]
  for = "/*"
  [headers.values]
    X-Frame-Options = "SAMEORIGIN"
    X-Content-Type-Options = "nosniff"
    Referrer-Policy = "strict-origin-when-cross-origin"
```

> **注**: マルチページ構成のためリダイレクト設定は不要。各 HTML への直リンクが有効。

- パンくず（任意）: `トップ ＞ 事業内容` の形でラベル上部に小さく表示。**推奨: 設置**。
