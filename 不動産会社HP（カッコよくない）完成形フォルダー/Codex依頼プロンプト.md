# 株式会社やまぶき不動産 ホームページ実装依頼

あなたは熟練のフロントエンドエンジニアです。下記の通り、不動産会社のコーポレートサイトをマルチページ構成（6 ページ）で実装してください。

## 1. 入力ファイル

| ファイル | 役割 |
|---|---|
| `Codex依頼仕様書.md` | **本依頼の唯一の正典**。すべての仕様はこのドキュメントに記載されている。実装で迷ったら必ず仕様書を参照すること。 |
| `index.html` | 既存のシングルページ実装。マルチページ化に伴い**全面的に書き換え**が必要。 |

| `script.js` | 既存のメニュー・フォーム制御 JS。マルチページ対応に拡張。 |
| `netlify.toml` | 既存。仕様書 第 2.4 章の内容に更新（X-Frame-Options を SAMEORIGIN、Referrer-Policy を追加）。 |

| `assets/logo.jpg` | フッターロゴ。 |

## 2. タスク

`Codex依頼仕様書.md` の **第 1 章〜第 11 章すべての仕様** を満たすように、以下を実装してください。

### 2.1 ページ作成（6 ページ）
- `index.html` … トップページ（既存ファイルを書き換え）
- `service.html` … 事業内容（新規作成）
- `property.html` … 物件情報（新規作成）
- `company.html` … 会社概要（新規作成）
- `access.html` … アクセス（新規作成）
- `contact.html` … お問い合わせ（新規作成）

仕様書 **第 3 章（ヘッダー・フッター共通仕様）** と **第 4 章（各ページ詳細）** に従って実装してください。

### 2.2 ヘッダー・フッターの実装方針
- 全ページに同一のヘッダー・フッター HTML を**直接コピペで埋め込む**（fetch やテンプレートエンジン不使用、Netlify 静的ホスティングで完結する形）。
- 現在ページのナビ項目には `class="is-active"` と `aria-current="page"` を付与する。

### 2.3 デザイン
仕様書 **第 5 章** のカラーパレット・タイポグラフィ・余白・ボタン仕様に従う。
- メインカラー: `#F8B500`
- 見出しフォント: Noto Serif JP
- 本文フォント: Noto Sans JP
- 英字フォント: Inter
- Google Fonts は全ページの `<head>` に同じ `<link>` を追加。

### 2.4 フォーム（Netlify Forms）
仕様書 **第 6 章** に従い、4 種類のフォームを実装。
- 未公開物件メール会員（`property.html` 内、`name="member"`）
- 売却相談（`contact.html` 内、`name="seller"`）
- 購入相談（`contact.html` 内、`name="buyer"`）
- 住宅会社紹介相談（`contact.html` 内、`name="housing"`）

すべてに以下を付与:
- `data-netlify="true"`
- `data-netlify-honeypot="bot-field"`
- 隠し `<input type="hidden" name="form-name" value="<フォーム名>">`
- 視覚非表示の honeypot `<p hidden><label>Don't fill: <input name="bot-field"></label></p>`

送信成功時は同ページに留まりメッセージ表示。既存 `script.js` の `.form-message` を流用すること。

### 2.5 SEO・メタ情報
仕様書 **第 7 章** に従い:
- 各ページの `<title>` `<meta name="description">` を 7.1 章の表通りに設定。
- 全ページに OGP / Twitter Card メタタグを設置（`og:url` のドメインは `https://yamabuki-re.co.jp/` で仮置き）。
- 全ページに `RealEstateAgent` の JSON-LD を設置。

### 2.6 アクセス（Google Maps）
仕様書 **第 4.5.2 節** の iframe コードを `access.html` に設置。

### 2.7 提携ハウスメーカー 10 社（`service.html`）
仕様書 **第 4.2.4 節** の通り、**ロゴ画像は未取得のためテキストプレースホルダーで実装**。差し替えやすい構造（HTML コメントで `<img>` の差し替え位置を明示）にすること。

### 2.8 既存資産との関係
- `assets/logo-header.png` と `assets/logo.jpg` はそのまま使用。
- 仕様書 第 8.1 章の表にある未作成画像（hero.jpg、og-image.jpg、page-hero/*.jpg、hm-logos/*.png、favicon.ico）は**実ファイルがない前提**で、`<img src>` などのパスだけ正しく書いておく。ファイルは後日配置される。

- **依頼者が指定したコピー（代表挨拶・由来・各セクション本文）は一字一句変更しない**。仕様書の付録 A・付録 B の本文は完全に保持すること。
- ハウスメーカー 10 社の社名表記は仕様書の通り（「大和ハウス工業」「WITHDOM 建築設計」など、正式名称を維持）。
- 電話番号は **`043-311-7171`**（既存 index.html の `03-1234-5678` は仮値なので必ず差し替え）。
- 「資本金」は会社概要に**載せない**。
- 「免許番号」は **`取得申請中`** と表記。
- 削除する機能: ブログ／お客様の声／採用情報／物件一覧／法務系専用ページ／SNS リンク。
- 縦書きヒーロー（既存）は維持。CSS の `writing-mode: vertical-rl` を活用。
